# ClinicFlow adaptive UI (React + JavaScript)

## Run it
1. Install Node.js (the LTS version) from nodejs.org.
2. Open this folder in VS Code, then open a terminal (Ctrl + `).
3. Run `npm install` (only needed once).
4. Run `npm run dev` and open the address it prints (usually http://localhost:5173).
5. Drag the browser window narrower and wider to watch the layout adapt.

## Where things are
- `src/adaptiveLayout.jsx` is the adaptive UI (breakpoints, phone and wide layouts).
- `src/screens.jsx` has every screen from the sketches.
- `src/appData.js` is the sample data. Replace it when the database is ready.
- `src/App.jsx` lists the pages of the app.
